# Fill checklist (after `stub-week.mjs`)

Use this when turning a stub week into a shippable issue.

## Before writing

- [ ] Confirm `weekOf` (YYYY-MM-DD Monday) and issue number
- [ ] Run / confirm noise count → ratio = noiseCount ÷ 5
- [ ] Skim fundraising / hiring / board / runway / GTM surfaces for the week

## Signal (5)

For each pick:

- [ ] Real URL (not placeholder)
- [ ] Source credited
- [ ] Category set (`fundraising` | `hiring` | `product` | `leadership` | `market`)
- [ ] `whyItMatters` names a stake and a decision — not a summary of the headline
- [ ] Position 1–5 ordered by operator usefulness, not buzz

## Noise (3)

- [ ] Dry offense in 1–2 sentences
- [ ] Satire OK; do not invent noise as if it were measured primary signal

## Ship

- [ ] Week `note` is one line on the noise theme
- [ ] InTheRoom UTMs will pick up `week-{weekOf}` from props (no hardcode needed)
- [ ] Newsletter still stubbed
- [ ] Spot-check homepage: WeeklySignal visually primary; ratio + share control present
